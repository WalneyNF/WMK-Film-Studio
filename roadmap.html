Como funciona: os estados abaixo são os marcos registrados neste arquivo, e não uma consulta em tempo real ao GitHub. Para alterar o progresso oficial, atualize o array fases no código HTML e faça commit. Os filtros são aplicados nesta página; exporte CSV para compartilhar uma visão das tarefas.

Entregas iniciais da v0.20.2

Scripts de diagnóstico de Windows e organização de pastas de projeto estão sendo adicionados em scripts/. Essas ferramentas são utilitários independentes, ainda não integrados aos painéis do editor. Consulte o manual das ferramentas WMK.

Critérios para marcar como concluído

  1. Código integrado na branch de distribuição.
  2. Compilação e testes relevantes aprovados no GitHub Actions.
  3. Recurso verificado manualmente no cenário de uso documentado.
  4. Manual, CHANGELOG e release atualizados quando aplicável.

O ZIP de estudos v0.20.1 foi compilado e publicado, mas a aplicação da nova identidade à distribuição depende de um novo build/release.
